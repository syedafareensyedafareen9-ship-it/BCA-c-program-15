C PROGRAMS 1-20

This folder contains 20 separate C source files:
prog1.c through prog20.c

The programs are based on the three PDFs supplied in the conversation.
Compile an individual program, for example:
    gcc prog1.c -o prog1
    ./prog1

Note:
- prog9.c calculates digit powers using integer multiplication, so it does not require linking the math library.
- prog20.c creates/uses students.txt in the current working directory.
- Input strings/names in prog17.c and prog20.c are read as single words (spaces are not supported), matching the source examples.
